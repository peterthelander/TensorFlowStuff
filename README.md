# TensorFlow Learning Notebooks

A small historical scratchpad for learning TensorFlow and experimenting with its
programming model. This is a learning archive rather than an application or library.

## Contents

- `first_steps_with_tensor_flow.ipynb`: initial TensorFlow experiments.
- `The_tensorflow_version_magic.ipynb`: further exploratory notebook work.

Open the notebooks in Jupyter to inspect their code and saved outputs. Executing
them requires a compatible Python/TensorFlow environment; dependencies are not
pinned, and compatibility with current releases has not been checked. Historical
outputs are not evidence of current runtime behavior.

**Status:** historical learning material. For more recent AI workflow experiments,
see [AI Orchestrator](https://github.com/peterthelander/ai-orchestrator) and
[Entourage](https://github.com/peterthelander/entourage).
